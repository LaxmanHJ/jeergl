01

Intrinsic Equity Valuation Engine

What is a share actually worth?

  • React.js
  • Node.js
  • Chart.js
  • REST APIs

Try the model

Move the sliders to price a dividend-paying share with the Dividend Discount Model and CAPM.

Required return12.4%
Intrinsic value per share₹375

Value = dividend ÷ (required return − growth). Assumes a 7% risk-free rate and a 13% market return. An illustration, not investment advice.

The problem

A share's price is easy to look up. Whether that price is justified by the dividends the company pays is not.

My solution

A full-stack tool that values a share from its dividends with the Dividend Discount Model, uses CAPM and the stock's beta to set a risk-adjusted discount rate, and then backtests the result against five years of financial data.

What it does

  • Dividend Discount Model valuation
  • CAPM discount rate from each stock's beta
  • Five-year backtest of valuation-based strategies
  • Sharpe ratio, drawdown and benchmark return charts

Architecture

  1. React.js interface
  2. REST APIs on Node.js
  3. DDM and CAPM valuation, backtesting
  4. Chart.js visualisations
5 years
of financial data backtested

02

Equity Tracker & Quantitative Analyzer

Market data, indicators and a prediction model in one place.

  • Node.js
  • FastAPI
  • Pandas
  • NumPy
  • SQLite
  1. Node.js application
  2. FastAPI service in Python
  3. Pandas, NumPy and the ML model
  4. SQLite cache
  5. External market data API

How the pieces fit together.

The problem

Analysing a stock means fetching the same market data again and again and recomputing the same indicators every time.

My solution

A quantitative analysis platform split in two: a Node.js application for the product and a Python FastAPI service for the numerical work with Pandas and NumPy. It computes RSI, MACD and momentum indicators, runs a machine-learning prediction model and caches API responses in SQLite.

What it does

  • Machine-learning price prediction
  • RSI, MACD and momentum indicators
  • SQLite caching of external API responses
